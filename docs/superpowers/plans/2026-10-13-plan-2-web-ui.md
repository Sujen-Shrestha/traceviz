# traceviz Plan 2: Web API + React UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `traceviz serve` starts a local web app where you enter a host, watch hops stream into a table and onto an animated offline world map, read the trace summary, and run MTR-style monitoring with a live per-hop latency chart.

**Architecture:** A FastAPI app (`traceviz.web.app.create_app`) wraps the existing `SessionManager`: REST to start/stop/read sessions, one WebSocket per session streaming `session_message` snapshots (state + summary). A React + TypeScript (Vite) single-page app in `frontend/` consumes them; the map is drawn with d3-geo from bundled Natural Earth outlines (world-atlas), the monitor chart with uPlot. In production FastAPI serves the built `frontend/dist`.

**Tech Stack:** FastAPI 0.141.1, uvicorn[standard] 0.54.0; React 19.3.0, TypeScript 7.0.2, Vite 8.3.1, Vitest 5.0.2, Testing Library, d3-geo 3.1.1, topojson-client 3.1.0, world-atlas 2.0.2, uPlot 1.6.32; pnpm 10.34.6 (run via `npx -y pnpm@10.34.6`).

**Spec:** `docs/superpowers/specs/2026-10-13-traceviz-design.md` (sections 2.2 Web, 3.1–3.2, 4, 5)

## Scope (phase 2 of 5)

In: Trace view, Monitor view (live chart), health banners, `serve` command, static serving, plus the SQLite/concurrency items deferred from Plan 1's review.
Out (later plans): Speed view and History view (Plan 4), TUI (Plan 3), Docker and SIGTERM handling (Plan 5).

**Decisions made while planning:**
- Toolchain verified in a throwaway spike on this machine: system npm 9.2 crashes (`Cannot read properties of null (reading 'edgesOut')`), so the frontend uses **pnpm 10.34.6 via `npx`**, pinned in `packageManager`. TypeScript 7 needs `src/vite-env.d.ts` for CSS imports; pnpm's strictness needs `@types/topojson-specification` and `@testing-library/dom` as direct dev deps.
- All pinned versions were published at least two weeks before 2026-10-13.
- Monitor chart data is built client-side from the live WebSocket snapshots (one point per second per hop, last 300 points). Persisted monitor samples are for Plan 4's History view.
- A session stops when its last WebSocket subscriber disconnects (existing `SessionManager` behaviour): closing the browser tab stops the probe.
- `GET /api/sessions/{id}` returns the current snapshot (used by tests and for reconnects); history endpoints come in Plan 4.

## Global Constraints

- Server binds `127.0.0.1` by default; any other host requires the explicit `--host` flag and prints a warning. Default port `8080`.
- Web layer depends only on `SessionManager`, `TraceState`, `summarize`, `resolve_target` — never on mtr or SQLite directly.
- Every WebSocket message is `{"type": "state", "id": <int>, ...TraceState.to_dict(), "summary": TraceSummary.to_dict()}`.
- Repository (SQLite) calls never run on the event loop: always `asyncio.to_thread`.
- SQLite connections set `PRAGMA busy_timeout=5000`; `init_db` refuses a database whose `user_version` is newer than `SCHEMA_VERSION`.
- Frontend: TypeScript strict, no `any`; package versions pinned exactly (no `^`); commands run with `npx -y pnpm@10.34.6 --dir frontend …` from the repo root.
- Footer attribution: DB-IP text from `/api/health` plus "Map data: Natural Earth".
- Python commands: `uv run …` from the repo root.

## Review Focus

1. **Browser tab closed mid-monitor** → the WebSocket disconnect stops the session and kills mtr; a second open tab keeps it alive until it too closes. Pinned in Task 3.
2. **Bad input from the form** (unresolvable host, `--help`, max_hops 0, a 4th concurrent session) → clear HTTP 422/429 with a human-readable `detail`, shown in the UI as an error banner. Pinned in Tasks 2 and 5/8.
3. **mtr unusable at startup** (no NET_RAW) → `/api/health` reports it and the UI shows an alert banner instead of failing silently on Start. Pinned in Tasks 2 and 8.
4. **Unknown session id** on WebSocket, GET or stop → 4404 close / 404, never a 500. Pinned in Tasks 2 and 3.
5. **Hops without coordinates** (local, unknown, missing geo DB) → map draws only locatable hops, merges repeated coordinates, shows "No locatable hops yet" when none; table still lists every hop. Pinned in Tasks 5 and 7.

```python
    """Records which threads repository methods run on."""

    def __init__(self, engine):
        super().__init__(engine)
        self.threads: set[int] = set()

    def create_trace(self, *args):
        self.threads.add(threading.get_ident())
        return super().create_trace(*args)

    def finish_trace(self, *args):
        self.threads.add(threading.get_ident())
        return super().finish_trace(*args)

    def add_monitor_samples(self, rows):
        self.threads.add(threading.get_ident())
```

```python
from datetime import datetime
from pathlib import Path

from sqlalchemy import Engine, event
from sqlalchemy.exc import OperationalError
from sqlmodel import Session, SQLModel, create_engine, select

from traceviz.core.sessions.state import HopStats, TraceState
from traceviz.core.store.models import HopRecord, MonitorSampleRecord, TraceRecord

SCHEMA_VERSION = 1
BUSY_TIMEOUT_MS = 5000


class SchemaTooNew(RuntimeError):
    """The database was written by a newer traceviz."""


def init_db(path: Path) -> Engine:
    path.parent.mkdir(parents=True, exist_ok=True)
    engine = create_engine(f"sqlite:///{path}", connect_args={"check_same_thread": False})

    @event.listens_for(engine, "connect")
    def _set_busy_timeout(dbapi_conn, _record) -> None:
        dbapi_conn.execute(f"PRAGMA busy_timeout={BUSY_TIMEOUT_MS}")

    with engine.begin() as conn:
        version = conn.exec_driver_sql("PRAGMA user_version").scalar() or 0
        if version > SCHEMA_VERSION:
            raise SchemaTooNew(
                f"database {path} uses schema v{version}, newer than this traceviz "
                f"(v{SCHEMA_VERSION}); upgrade traceviz"
            )
        conn.exec_driver_sql("PRAGMA journal_mode=WAL")
    try:
        SQLModel.metadata.create_all(engine)
    except OperationalError as e:
        # Another process (CLI vs server) created the tables between our check and create.
        if "already exists" not in str(e):
            raise
        SQLModel.metadata.create_all(engine)
    with engine.begin() as conn:
        conn.exec_driver_sql(f"PRAGMA user_version={SCHEMA_VERSION}")
    return engine
```

```python
import asyncio
import logging
from collections.abc import AsyncIterator, Callable
from contextlib import aclosing
from dataclasses import dataclass, field
from datetime import UTC, datetime

from traceviz.core.geo.lookup import GeoLookup
from traceviz.core.probe.engine import ProbeEngine, ProbeError, ProbeProtocol
from traceviz.core.probe.target import ResolvedTarget
from traceviz.core.sessions.state import SessionKind, TraceState
from traceviz.core.store.models import MonitorSampleRecord
from traceviz.core.store.repo import TraceRepository

log = logging.getLogger(__name__)


class TooManySessions(RuntimeError):
    """The concurrent session limit has been reached."""


class SessionNotFound(KeyError):
    """No session with that id exists in this manager."""


@dataclass
class _Session:
    id: int
    state: TraceState
    task: asyncio.Task | None = None
    subscribers: set[asyncio.Queue] = field(default_factory=set)
    done: asyncio.Event = field(default_factory=asyncio.Event)
    # hop index -> (sent, received, sum_ms) at the last successful monitor flush
    flushed: dict[int, tuple[int, int, float]] = field(default_factory=dict)


class SessionManager:
    def __init__(
        self,
        engine: ProbeEngine,
        geo: GeoLookup,
        repo: TraceRepository,
        *,
        max_sessions: int = 3,
        trace_timeout_s: float = 300.0,
        sample_interval_s: float = 10.0,
        clock: Callable[[], datetime] = lambda: datetime.now(UTC),
    ) -> None:
        self.engine = engine
        self.geo = geo
        self.repo = repo
        self.max_sessions = max_sessions
        self.trace_timeout_s = trace_timeout_s
        self.sample_interval_s = sample_interval_s
        self.clock = clock
        self._sessions: dict[int, _Session] = {}
        self._starting = 0

    def _get(self, session_id: int) -> _Session:
        try:
            return self._sessions[session_id]
        except KeyError:
            raise SessionNotFound(session_id) from None

    def snapshot(self, session_id: int) -> TraceState:
        return self._get(session_id).state.snapshot()

    async def start(
        self,
        target: ResolvedTarget,
        *,
        kind: SessionKind = "trace",
        protocol: ProbeProtocol = "icmp",
        max_hops: int = 30,
        cycles: int = 10,
    ) -> int:
        active = sum(1 for s in self._sessions.values() if not s.done.is_set()) + self._starting
        if active >= self.max_sessions:
            raise TooManySessions(f"at most {self.max_sessions} sessions can run at once")
        state = TraceState(target=target.target, target_ip=target.ip, protocol=protocol, kind=kind)
        self._starting += 1  # reserve the slot across the await below
        try:
            session_id = await asyncio.to_thread(self.repo.create_trace, state, self.clock())
        finally:
            self._starting -= 1
        session = _Session(session_id, state)
        self._sessions[session.id] = session
        session.task = asyncio.create_task(
            self._run(session, max_hops, None if kind == "monitor" else cycles)
        )
        return session.id

    async def _run(self, s: _Session, max_hops: int, cycles: int | None) -> None:
        state = s.state
        timeout = self.trace_timeout_s if state.kind == "trace" else None
        sampler = asyncio.create_task(self._sample_loop(s)) if state.kind == "monitor" else None
        try:
            async with asyncio.timeout(timeout):
                events = self.engine.run(state.target_ip, state.protocol, max_hops, cycles)
                async with aclosing(events):
                    async for event in events:
                        hop = state.apply(event)
                        if hop.ip and hop.geo is None:
                            hop.geo = self.geo.lookup(hop.ip)
                        self._publish(s)
            state.status = "completed"
        except asyncio.CancelledError:
            state.status = "stopped"
        except TimeoutError:
            state.status = "failed"
            state.error = f"timed out after {timeout:.0f}s"
        except ProbeError as e:
            state.status = "failed"
            state.error = str(e)
        except Exception as e:
            state.status = "failed"
            state.error = f"{type(e).__name__}: {e}"
        finally:
            if sampler:
                sampler.cancel()
                await asyncio.gather(sampler, return_exceptions=True)
            await self._finish(s)

    async def _finish(self, s: _Session) -> None:
        if s.state.kind == "monitor":
            await self._save_samples(s)
        await asyncio.to_thread(self.repo.finish_trace, s.id, s.state.snapshot(), self.clock())
        s.done.set()
        self._publish(s)

    async def _sample_loop(self, s: _Session) -> None:
        while True:
            await asyncio.sleep(self.sample_interval_s)
            await self._save_samples(s)

    async def _save_samples(self, s: _Session) -> None:
        try:
            await self._flush_samples(s)
        except Exception:
            log.exception("could not save monitor samples for session %s", s.id)

    async def _flush_samples(self, s: _Session) -> None:
        now = self.clock()
        rows = []
        flushed = dict(s.flushed)
        for hop in s.state.hops:
            prev_sent, prev_received, prev_sum = flushed.get(hop.index, (0, 0, 0.0))
            d_sent = hop.sent - prev_sent
            d_received = hop.received - prev_received
            if d_sent <= 0 and d_received <= 0:
                continue
            avg = (hop.sum_ms - prev_sum) / d_received if d_received else None
            rows.append(
                MonitorSampleRecord(
                    trace_id=s.id, ts=now, hop_index=hop.index,
                    sent=d_sent, received=d_received, avg_ms=avg,
                )
            )
            flushed[hop.index] = (hop.sent, hop.received, hop.sum_ms)
        if rows:
            await asyncio.to_thread(self.repo.add_monitor_samples, rows)
        s.flushed = flushed  # only advance after a successful write, so totals stay exact

    def _publish(self, s: _Session) -> None:
        snap = s.state.snapshot()
        for queue in s.subscribers:
            if queue.full():
                queue.get_nowait()
            queue.put_nowait(snap)

    async def subscribe(self, session_id: int) -> AsyncIterator[TraceState]:
        s = self._get(session_id)
        queue: asyncio.Queue[TraceState] = asyncio.Queue(maxsize=1)
        queue.put_nowait(s.state.snapshot())
        s.subscribers.add(queue)
        try:
            while True:
                snap = await queue.get()
                yield snap
                if snap.status != "running":
                    return
        finally:
            s.subscribers.discard(queue)
            if not s.subscribers and not s.done.is_set():
                await self.stop(session_id)

    async def stop(self, session_id: int) -> None:
        s = self._get(session_id)
        if s.task and not s.task.done():
            s.task.cancel()
            await asyncio.gather(s.task, return_exceptions=True)
        if not s.done.is_set():
            # Cancelled before _run's first step (or during its cleanup), so finish here.
            if s.state.status == "running":
                s.state.status = "stopped"
            await self._finish(s)

    async def wait(self, session_id: int) -> TraceState:
        s = self._get(session_id)
        await s.done.wait()
        return s.state.snapshot()

    async def close(self) -> None:
        for session_id in list(self._sessions):
            await self.stop(session_id)
```

```python
import asyncio
import logging
from collections.abc import Callable
from contextlib import asynccontextmanager
from pathlib import Path
from typing import Literal

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

from traceviz.core.geo.download import ATTRIBUTION
from traceviz.core.probe.engine import ProbeError
from traceviz.core.probe.target import InvalidTarget, ResolvedTarget, resolve_target
from traceviz.core.sessions.manager import SessionManager, SessionNotFound, TooManySessions
from traceviz.web.serialize import session_message

log = logging.getLogger(__name__)


class StartRequest(BaseModel):
    target: str = Field(min_length=1, max_length=253)
    kind: Literal["trace", "monitor"] = "trace"
    protocol: Literal["icmp", "udp", "tcp"] = "icmp"
    max_hops: int = Field(30, ge=1, le=64)
    cycles: int = Field(10, ge=1, le=100)


def create_app(
    manager: SessionManager,
    *,
    geo_available: bool,
    static_dir: Path | None = None,
    resolve: Callable[[str], ResolvedTarget] = resolve_target,
) -> FastAPI:
    @asynccontextmanager
    async def lifespan(app: FastAPI):
        try:
            await manager.engine.self_check()
        except ProbeError as e:
            app.state.probe_error = str(e)
            log.warning("probe self-check failed: %s", e)
        yield
        await manager.close()

    app = FastAPI(title="traceviz", lifespan=lifespan)
    app.state.probe_error = None

    @app.get("/api/health")
    def health() -> dict:
        return {
            "probe_ok": app.state.probe_error is None,
            "probe_error": app.state.probe_error,
            "geo_available": geo_available,
            "attribution": ATTRIBUTION,
        }

    @app.post("/api/sessions", status_code=201)
    async def start_session(req: StartRequest) -> dict:
        try:
            target = await asyncio.to_thread(resolve, req.target)
        except InvalidTarget as e:
            raise HTTPException(422, str(e)) from e
        try:
            sid = await manager.start(
                target, kind=req.kind, protocol=req.protocol, max_hops=req.max_hops, cycles=req.cycles
            )
        except TooManySessions as e:
            raise HTTPException(429, str(e)) from e
        return {"id": sid, "target": target.target, "target_ip": target.ip}

    @app.get("/api/sessions/{sid}")
    def get_session(sid: int) -> dict:
        try:
            return session_message(sid, manager.snapshot(sid))
        except SessionNotFound as e:
            raise HTTPException(404, "no such session") from e

    @app.post("/api/sessions/{sid}/stop", status_code=204)
    async def stop_session(sid: int) -> None:
        try:
            await manager.stop(sid)
        except SessionNotFound as e:
            raise HTTPException(404, "no such session") from e

    return app
```

```python
    @app.websocket("/ws/sessions/{sid}")
    async def session_stream(ws: WebSocket, sid: int) -> None:
        await ws.accept()
        try:
            manager.snapshot(sid)
        except SessionNotFound:
            await ws.close(code=4404)
            return

        async def pump() -> None:
            async with aclosing(manager.subscribe(sid)) as states:
                async for state in states:
                    await ws.send_json(session_message(sid, state))

        async def until_disconnect() -> None:
            while (await ws.receive())["type"] != "websocket.disconnect":
                pass

        pump_task = asyncio.create_task(pump())
        watch_task = asyncio.create_task(until_disconnect())
        done, pending = await asyncio.wait({pump_task, watch_task}, return_when=asyncio.FIRST_COMPLETED)
        for task in pending:
            task.cancel()  # cancelling pump closes the subscription -> may stop the session
        await asyncio.gather(*pending, return_exceptions=True)
        if pump_task in done:
            error = pump_task.exception()
            if error is not None and not isinstance(error, (WebSocketDisconnect, RuntimeError)):
                log.error("session stream %s failed", sid, exc_info=error)
            with contextlib.suppress(RuntimeError, WebSocketDisconnect):
                await ws.close()
```

```ts
import type { Health, SessionMessage, StartRequest, StartResponse } from "./types";

export class ApiError extends Error {
  constructor(message: string, readonly status: number) {
    super(message);
    this.name = "ApiError";
  }
}

interface ErrorBody {
  detail?: string | { msg: string }[];
}

async function parse<T>(res: Response): Promise<T> {
  if (!res.ok) {
    let message = `${res.status} ${res.statusText}`.trim();
    try {
      const body = (await res.json()) as ErrorBody;
      if (typeof body.detail === "string") message = body.detail;
      else if (Array.isArray(body.detail)) message = body.detail.map((d) => d.msg).join("; ");
    } catch {
      // not JSON: keep the status line
    }
    throw new ApiError(message, res.status);
  }
  if (res.status === 204) return undefined as T;
  return (await res.json()) as T;
}

export function getHealth(): Promise<Health> {
  return fetch("/api/health").then((r) => parse<Health>(r));
}

export function startSession(req: StartRequest): Promise<StartResponse> {
  return fetch("/api/sessions", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(req),
  }).then((r) => parse<StartResponse>(r));
}

export function stopSession(id: number): Promise<void> {
  return fetch(`/api/sessions/${id}/stop`, { method: "POST" }).then((r) => parse<void>(r));
}

export function openSessionSocket(
  id: number,
  onMessage: (msg: SessionMessage) => void,
  onClose?: (code: number) => void,
): () => void {
  const scheme = window.location.protocol === "https:" ? "wss" : "ws";
  const ws = new WebSocket(`${scheme}://${window.location.host}/ws/sessions/${id}`);
  ws.onmessage = (event) => onMessage(JSON.parse(event.data as string) as SessionMessage);
  ws.onclose = (event) => onClose?.(event.code);
  return () => ws.close();
}
```

```ts
import type { Hop } from "../types";

export interface MapPoint {
  hops: number[];
  lat: number;
  lon: number;
  label: string;
  approximate: boolean;
}

export function mapPoints(hops: Hop[]): MapPoint[] {
  const points: MapPoint[] = [];
  for (const h of hops) {
    const g = h.geo;
    if (!g || g.status !== "geo" || g.lat === null || g.lon === null) continue;
    const prev = points.at(-1);
    if (prev && prev.lat === g.lat && prev.lon === g.lon) {
      prev.hops.push(h.hop);
      prev.approximate ||= g.approximate;
      continue;
    }
    const label = [g.city, g.country].filter(Boolean).join(", ") || (g.country_name ?? "");
    points.push({ hops: [h.hop], lat: g.lat, lon: g.lon, label, approximate: g.approximate });
  }
  return points;
}
```

```ts
import type { SessionMessage } from "./types";

export interface HopSeries {
  hop: number;
  label: string;
  values: (number | null)[];
}

export interface MonitorSeries {
  times: number[];
  hops: HopSeries[];
}

export const MAX_POINTS = 300;
const MIN_INTERVAL_S = 1;

export function emptySeries(): MonitorSeries {
  return { times: [], hops: [] };
}

/** Add one point per answering hop (its last RTT) at time `t` (unix seconds). */
export function appendSample(series: MonitorSeries, msg: SessionMessage, t: number): MonitorSeries {
  const lastTime = series.times.at(-1);
  if (lastTime !== undefined && t - lastTime < MIN_INTERVAL_S) return series;
  const previous = new Map(series.hops.map((h) => [h.hop, h]));
  const hops: HopSeries[] = msg.hops
    .filter((h) => h.ip !== null)
    .map((h) => {
      const history = previous.get(h.hop)?.values ?? new Array<number | null>(series.times.length).fill(null);
      return { hop: h.hop, label: `${h.hop}: ${h.hostname ?? h.ip}`, values: [...history, h.last_ms] };
    });
  for (const old of series.hops) {
    if (!hops.some((h) => h.hop === old.hop)) hops.push({ ...old, values: [...old.values, null] });
  }
  hops.sort((a, b) => a.hop - b.hop);
  const times = [...series.times, t];
  const drop = Math.max(0, times.length - MAX_POINTS);
  return { times: times.slice(drop), hops: hops.map((h) => ({ ...h, values: h.values.slice(drop) })) };
}
```

```tsx
const projection = geoNaturalEarth1().fitSize([WIDTH, HEIGHT], { type: "Sphere" });
const path = geoPath(projection);
const spherePath = path({ type: "Sphere" }) ?? "";
const graticulePath = path(geoGraticule10()) ?? "";
const landPath = path(land) ?? "";

export function WorldMap({ hops }: { hops: Hop[] }) {
  const points = useMemo(() => mapPoints(hops), [hops]);
  const arcs = points.slice(1).map((p, i) => {
    const from = points[i];
    return path({ type: "LineString", coordinates: [[from.lon, from.lat], [p.lon, p.lat]] }) ?? "";
  });
  return (
    <svg className="world-map" viewBox={`0 0 ${WIDTH} ${HEIGHT}`} role="img" aria-label="Route map">
      <path className="sphere" d={spherePath} />
      <path className="graticule" d={graticulePath} />
      <path className="land" d={landPath} data-testid="land" />
      {arcs.map((d, i) => (
        <path key={`arc-${i}`} className="arc" d={d} data-testid="arc" style={{ animationDelay: `${i * 0.3}s` }} />
      ))}
      {points.map((p) => {
        const xy = projection([p.lon, p.lat]);
        if (!xy) return null;
        const hopsLabel = p.hops.join(",");
        return (
          <g
            key={hopsLabel}
            className={p.approximate ? "hop-marker approx" : "hop-marker"}
            transform={`translate(${xy[0]},${xy[1]})`}
            data-testid="marker"
          >
            <title>{`Hop ${p.hops.join(", ")}: ${p.label}${p.approximate ? " (approximate)" : ""}`}</title>
            <circle r={5} />
            <text x={8} y={4}>{`${hopsLabel} ${p.label}`}</text>
          </g>
        );
      })}
      {points.length === 0 && (
        <text className="map-empty" x={WIDTH / 2} y={HEIGHT - 24} textAnchor="middle">No locatable hops yet</text>
      )}
    </svg>
  );
}
```

```tsx
import { useEffect, useRef } from "react";
import uPlot from "uplot";

import type { MonitorSeries } from "../monitorSeries";

const COLORS = ["#4cc9f0", "#f72585", "#b5e48c", "#ffd166", "#9b5de5", "#00f5d4", "#f15bb5", "#fee440", "#ff8c42", "#8ecae6"];

function toData(series: MonitorSeries): uPlot.AlignedData {
  return [series.times, ...series.hops.map((h) => h.values)] as uPlot.AlignedData;
}

export function LatencyChart({ series }: { series: MonitorSeries }) {
  const container = useRef<HTMLDivElement>(null);
  const plot = useRef<uPlot | null>(null);
  const hopKey = series.hops.map((h) => h.hop).join(",");

  useEffect(() => {
    if (!container.current) return;
    const options: uPlot.Options = {
      width: container.current.clientWidth || 900,
      height: 260,
      scales: { x: { time: true } },
      axes: [{ stroke: "#9aa4b2" }, { stroke: "#9aa4b2", label: "ms" }],
      series: [{}, ...series.hops.map((h, i) => ({ label: h.label, stroke: COLORS[i % COLORS.length], width: 1.5 }))],
    };
    plot.current = new uPlot(options, toData(series), container.current);
    return () => {
      plot.current?.destroy();
      plot.current = null;
    };
    // Rebuild only when the set of hops changes; data updates go through setData below.
  }, [hopKey]);

  useEffect(() => {
    plot.current?.setData(toData(series));
  }, [series]);

  return (
    <section className="card">
      <h2>Latency per hop</h2>
      <div ref={container} />
    </section>
  );
}
```

`frontend/src/App.tsx`:
```tsx
import { useEffect, useRef, useState } from "react";
import { getHealth, openSessionSocket, startSession, stopSession } from "./api";
import { HopTable } from "./components/HopTable";
import { LatencyChart } from "./components/LatencyChart";
import { SummaryPanel } from "./components/SummaryPanel";
import { TargetForm } from "./components/TargetForm";
import { WorldMap } from "./map/WorldMap";
import { appendSample, emptySeries, type MonitorSeries } from "./monitorSeries";
import type { Health, SessionMessage, StartRequest } from "./types";

const message = (e: unknown) => (e instanceof Error ? e.message : String(e));

export function App() {
  const [health, setHealth] = useState<Health | null>(null);
  const [session, setSession] = useState<SessionMessage | null>(null);
  const [series, setSeries] = useState<MonitorSeries>(emptySeries);
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);
  const closeSocket = useRef<(() => void) | null>(null);

  useEffect(() => {
    getHealth().then(setHealth, (e: unknown) => setError(`Cannot reach the traceviz server: ${message(e)}`));
    return () => closeSocket.current?.();
  }, []);

  async function start(req: StartRequest) {
    setError(null);
    setBusy(true);
    closeSocket.current?.();
    setSession(null);
    setSeries(emptySeries());
    try {
      const { id } = await startSession(req);
      closeSocket.current = openSessionSocket(id, (msg) => {
        setSession(msg);
        if (msg.kind === "monitor") setSeries((s) => appendSample(s, msg, Date.now() / 1000));
      });
    } catch (e) {
      setError(message(e));
    } finally {
      setBusy(false);
    }
  }

  async function stop() {
    if (!session) return;
    try {
      await stopSession(session.id);
    } catch (e) {
      setError(message(e));
    }
  }

  return (
    <div className="app">
      <header>
        <h1>traceviz</h1>
        <span className="muted">visual traceroute</span>
      </header>
      {health && !health.probe_ok && (
        <div className="banner error" role="alert">Probing is unavailable: {health.probe_error}</div>
      )}
      {health && !health.geo_available && (
        <div className="banner warn">No geolocation database — run <code>traceviz fetch-geo</code> to see hop locations.</div>
      )}
      <TargetForm onStart={start} onStop={stop} running={session?.status === "running"} busy={busy} />
      {error && <div className="banner error" role="alert">{error}</div>}
      {session?.status === "failed" && (
        <div className="banner error" role="alert">Probe failed: {session.error}</div>
      )}
      {session?.suggest_other_protocol && (
        <div className="banner warn">No hops answered beyond the first. ICMP may be filtered — try TCP 443.</div>
      )}
      <section className="card map-card">
        <WorldMap hops={session?.hops ?? []} />
      </section>
      {session && <SummaryPanel summary={session.summary} />}
      {session?.kind === "monitor" && <LatencyChart series={series} />}
      {session && <HopTable hops={session.hops} />}
      <footer className="muted">{health?.attribution ?? ""} · Map data: Natural Earth</footer>
    </div>
  );
}
```
